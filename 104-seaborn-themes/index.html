Seaborn Themes

The seaborn python library is well known for its grey background and its general styling. However, there are few other built in styles available: darkgrid, white grid, dark, white and ticks.

You can set themes using the set_style() function of seaborn library. This post provides examples of different seaborn themes that you can use with your charts.

Libraries

Let's start by loading a few libraries:

  • matplotlib: for plotting
  • seaborn: for the themes
  • numpy for data generation
  • pandas for storing the data
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np
import pandas as pd

White grid

plt.title("whitegrid")
